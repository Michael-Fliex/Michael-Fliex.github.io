# 欢迎来到我的博客 🎉

大家好！这是我的个人博客，由 **Hexo** 框架搭建，托管在 **GitHub Pages** 上。

这里将用于记录：

- 📝 技术学习笔记
- 💡 生活感悟与随笔
- 🚀 项目实践与总结

## 关于博客

- 框架：[Hexo](https://hexo.io/zh-cn/)
- 部署：[GitHub Pages](https://pages.github.com/)
- 写作方式：Markdown 编写，一条命令即可发布

## 博客搭建参考教程

本次搭建参考了以下资料：

1. [Hexo 官方文档](https://hexo.io/zh-cn/docs/)
2. [Hexo 零基础搭建个人博客（CSDN）](https://blog.csdn.net/weixin_45019350/article/details/121901433)
3. [在 GitHub Pages 上部署 Hexo（官方文档）](https://hexo.io/zh-cn/docs/github-pages)

## 结语

希望能坚持记录、不断成长。欢迎常来逛逛！

```bash
# 发布一篇新文章
hexo new "我的新文章"
hexo clean && hexo generate
hexo deploy
```
